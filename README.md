# AURA X — промо-лендинг смартфона

Концепт сайта-визитки для вымышленного флагманского смартфона **AURA X**. Проект для портфолио: только фронтенд, без бэкенда.

**Стек:** React 19 · TypeScript · Vite · Framer Motion · Lenis (плавный скролл)

## Что внутри

| Раздел | Фишка |
| --- | --- |
| Прелоадер | Счётчик 0→100 и шторка, которая уезжает вверх |
| Первый экран | 3D-телефон на чистом CSS наклоняется вслед за курсором, вокруг «парят» карточки характеристик с параллаксом |
| Бегущая строка | Две наклонённые ленты, которые едут навстречу друг другу |
| Манифест | Слова «загораются» по мере прокрутки |
| Дизайн | Телефон можно крутить на 360° мышкой или пальцем; при смене цвета он разворачивается задней крышкой |
| Возможности | Бенто-сетка с подсветкой под курсором; живое сравнение 60 Гц и 144 Гц, заряжающаяся батарея, печатающий AI-ассистент |
| Камера | Слайдер «до/после» для ночного режима, видоискатель с зумом 0.6×–100×, горизонтальная галерея, которая едет при вертикальном скролле |
| Чип | SVG-дорожки платы прорисовываются, по ним бегут импульсы; анимированные бенчмарки |
| В жизни | Фотогалерея из трёх колонок, которые едут с разной скоростью |
| Модели | Три модели с 3D-превью и таблицей сравнения |
| FAQ | Аккордеон |
| Предзаказ | Обратный отсчёт с перелистывающимися цифрами и форма с валидацией (демо) |

Ещё: кастомный курсор, магнитные кнопки, индикатор прогресса скролла, навбар, который прячется при прокрутке вниз, и полноэкранное мобильное меню. Вёрстка адаптирована под телефон, планшет и десктоп, а при `prefers-reduced-motion` анимации отключаются.

Телефон собран из CSS-граней (`transform-style: preserve-3d`), без 3D-библиотек и картинок: см. `src/components/Phone.tsx`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Структура

```
src/
  components/   Phone (3D-телефон), Navbar, Preloader, Cursor, ui (Reveal, SplitText, Counter, Magnetic)
  sections/     секции страницы, у каждой свой .tsx и .css
  lib/          плавный скролл (Lenis)
  data.ts       тексты, цвета, модели, характеристики
  assets/img/   фотографии
```
